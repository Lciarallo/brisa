Your air conditioner, one click away.

Brisa puts your A/C in GNOME Quick Settings: power, temperature, modes, fan, swing, timers and sensors, with a live animation of what the unit is doing right now.

Live animation

Airflow colour follows the mode and its speed follows the fan. The vanes sweep while swing is on, and the flow calms down when the room reaches the target.

One-click control

Toggle power from Quick Settings. Pick a mode and the unit turns on in it. Several temperature clicks become a single request.

⏱️

Timers

Sleep timer, turn off in N hours, and turn on or off at a set time, every 30 minutes.

🧭

Air direction & features

Vertical and horizontal swing, special winds, energy saving, display light, purification and presets.

Sensors

Room temperature, humidity, PM2.5, air quality and filter life, when your unit has them.

Private by design

Install

  1. Install Brisa from extensions.gnome.org or the Extension Manager app. Or build it from source:
git clone https://github.com/Lciarallo/brisa.git
cd brisa
make install   # then log out and back in
  1. Open Extensions → Brisa → Settings and choose LG ThinQ or Home Assistant.
  2. LG: create a token at connect-pat.lgthinq.com. Home Assistant: create a long-lived token in your profile → Security.
  3. Paste the token (it goes to the GNOME Keyring), press Search, and pick your unit.

Security

  • Tokens are stored in the GNOME Keyring (libsecret), never in dconf.
  • HTTPS with certificate checks. Plain http only for Home Assistant on your local network, with a warning.
  • Redirects are refused, so the token is never replayed to another host. Responses are capped and every id used in a URL is validated.
  • No telemetry and no dependencies beyond GNOME's own libraries.

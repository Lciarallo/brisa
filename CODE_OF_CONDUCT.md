# Code of Conduct

Brisa is a GNOME extension and follows the **[GNOME Code of Conduct](https://conduct.gnome.org/)** in issues, pull requests, discussions and every other project space.

In short:

- be friendly and patient;
- be welcoming;
- be considerate;
- be respectful;
- be careful in the words you choose;
- when you disagree, try to understand why.

## Reporting

If someone breaks the code of conduct, email the maintainer at **luizeduardociarallo@gmail.com** with what happened, and links if you can. Reports are kept confidential. Maintainers may remove comments, commits or contributions that violate it, and may block repeat offenders.
